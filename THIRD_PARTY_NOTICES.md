# Third-Party Notices

EchoVoice ships some third-party code inside this package and downloads the
rest, at the user's request, from upstream projects. The two are listed
separately below, because the obligations differ.

  `media/kokoro/g2p/en-us.txt` is generated by our build tooling (not shipped
  in this package) from `misaki/data/us_gold.json` and `us_silver.json` of
  [hexgrad/misaki](https://github.com/hexgrad/misaki), the grapheme-to-phoneme

  `e820629`, SHA-256 verified, converted to one word per line in the same

  `media/kokoro/g2p/LICENSE-misaki-apache-2.0.txt`. The data belongs to its
  authors and is used here under their licence, with thanks. One honest note:
  the misaki repository does not yet state where the pronunciations in those
  files were originally sourced; a user asked in
  [hexgrad/misaki#107](https://github.com/hexgrad/misaki/issues/107)
  (2026-09-19) and we follow that issue. Should the answer change what the
  data file requires of us, the file — not the extension — will be relicensed
  or replaced.
- **CMUdict** — the same dictionary's third layer (words misaki lacks) derives

  tooling and is not shipped. Write to milo@echotools.dev for either.
- **en-us-echo.txt** — our own names and developer words, written by us; not

- **NRL Report 7948** — the letter-to-sound fallback rules derive from
  *Automatic Translation of English Text to Phonetics by Means of Letter-to-Sound

  **public domain** (17 U.S.C. §105). Attributed here so it need not be
  re-audited.
- **Kokoro tokenizer** — `media/kokoro/g2p/tokenizer.json` is data from the

## Downloaded at runtime, at the user's request

Pinned versions, SHA-256-verified before installation (see llms.txt):

- **Kokoro-82M v1.0 (ONNX)** — [onnx-community/Kokoro-82M-v1.0-ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX),
  **Apache-2.0**, derived from [hexgrad/Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M).
  The model weights and voice tensors are downloaded on first use; a copy of
  the Apache-2.0 licence text is written beside them at install time.
- **whisper.cpp** speech-to-text engine — [ggml-org/whisper.cpp](https://github.com/ggml-org/whisper.cpp),
  **MIT License** (© 2023-2026 The ggml authors). Downloaded only if you turn
  on voice input in EchoAvatar, as a command-line program built in the open by
  our runtime repository's workflow from one pinned upstream commit (the
  release notes name the commit and the build flags); a copy of the MIT text
  is written beside it at install time. It runs as a separate program that
  EchoAvatar starts; it is not linked into or shipped with this extension.
- **Whisper base.en model** — [ggerganov/whisper.cpp on Hugging Face](https://huggingface.co/ggerganov/whisper.cpp),
  **MIT License**, converted from [OpenAI Whisper](https://github.com/openai/whisper)
  (MIT). Downloaded with the engine above, re-hosted on our release and pinned
  by digest and size.
- **Piper** text-to-speech engine — [rhasspy/piper](https://github.com/rhasspy/piper),
  MIT License. Piper embeds espeak-ng (**GPL-3.0**) for phonemization; the
  engine is executed as a separate downloaded program, not linked into or
  shipped with this extension. Choosing the Piper voice therefore places
  GPL-licensed software on the user's disk, under its own licence; it is never
  part of this package.
- **Piper voice models** — [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices);
  per-voice licensing is stated in each model's upstream card.

The optional ElevenLabs tier calls the ElevenLabs API with the user's own
key under the user's own ElevenLabs terms.
