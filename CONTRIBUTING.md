# Contributing

This repository is **EchoVoice's public home**: documentation, releases,
issues, and ideas. The source code is developed privately and is not
published here - that's a deliberate decision, not an oversight.

What we warmly welcome here:

- **Bug reports** - the issue form asks for the Output log; it usually
  names the cause.
- **Ideas** - we ship updates weekly, and several shipped features started
  as a tester's suggestion (the Mute-covers-everything fix and two of the
  bundled music tracks came from exactly that).
- **Doc fixes** - typos and unclear sentences in these files: PRs welcome.

Questions about setup? Your AI coding partner can walk you through it -
ask it to read `AI-PARTNER.md` from this repo or from the installed
extension.
